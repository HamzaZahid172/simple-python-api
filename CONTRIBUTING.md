# Contributing

Contributions that improve API correctness, testing, documentation or accessibility are welcome.

1. Open an issue for larger changes, or pick a clearly scoped existing issue.
2. Create a feature branch from `main`.
3. Make one focused change and run `python -m unittest discover -s tests -v`.
4. Open a pull request that describes the problem, solution and test evidence.
5. Respect maintainers' feedback; avoid unrelated refactoring or artificial PRs.

Beginner-friendly ideas: add a real persistence adapter, API pagination, more invalid-input tests or an OpenAPI document.

Please do not include real user data, tokens or credentials in issues or examples.
